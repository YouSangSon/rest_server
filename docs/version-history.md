# 버전 변경 이력

## 📋 버전 관리 정책

이 문서는 REST Server 프로젝트의 모든 버전 변경 사항을 추적합니다. 각 변경 사항은 다음 형식을 따릅니다:

- **버전**: Semantic Versioning (MAJOR.MINOR.PATCH)
- **날짜**: 변경 날짜 (YYYY-MM-DD)
- **변경 유형**: FEATURE, FIX, BREAKING, DOCS, REFACTOR
- **설명**: 변경 사항에 대한 간단한 설명

## 📝 버전 업데이트 가이드

### 새로운 버전 생성 시

1. **버전 번호 결정**
   - MAJOR: 호환되지 않는 API 변경
   - MINOR: 새로운 기능 추가 (하위 호환)
   - PATCH: 버그 수정 (하위 호환)

2. **변경 이력 추가**
   - 새로운 버전 섹션 생성
   - 변경 유형 및 설명 작성
   - 날짜 기록

3. **문서 업데이트**
   - docs/README.md의 현재 버전 업데이트
   - 관련 문서의 버전 정보 수정

### 변경 유형 정의

- **FEATURE**: 새로운 기능 추가
- **FIX**: 버그 수정
- **BREAKING**: 호환되지 않는 변경
- **DOCS**: 문서만 변경
- **REFACTOR**: 코드 리팩토링
- **PERF**: 성능 개선
- **TEST**: 테스트 관련 변경
- **CHORE**: 빌드 프로세스, 도구 등
