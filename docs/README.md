# REST Server 프로젝트 문서

## 📚 문서 개요

이 문서는 REST Server 프로젝트의 포괄적인 기술 문서입니다. 프로젝트의 아키텍처, API, 배포 방법, 그리고 개발 가이드라인을 포함합니다.

## 🏗️ 문서 구조

```
docs/
├── README.md                    # 이 파일 - 문서 개요
├── architecture/                # 시스템 아키텍처 문서
│   ├── system-overview.md      # 시스템 전체 개요
│   ├── data-flow.md            # 데이터 흐름도
│   └── decision-records/       # 아키텍처 결정 기록
├── api/                        # API 문서
│   ├── endpoints.md            # API 엔드포인트 목록
│   └── schemas/                # API 스키마 정의
├── deployment/                 # 배포 관련 문서
│   ├── infrastructure.md       # 인프라 구성
│   └── monitoring.md           # 모니터링 및 로깅
├── development/                # 개발 가이드
│   ├── setup.md                # 개발 환경 설정
│   ├── coding-standards.md     # 코딩 표준
│   └── testing.md              # 테스트 가이드
└── version-history.md          # 버전 변경 이력
```

## 🔄 버전 관리

이 문서는 버전 관리 시스템을 따릅니다:

- **메이저 버전**: 주요 기능 추가나 아키텍처 변경
- **마이너 버전**: 새로운 기능 추가
- **패치 버전**: 버그 수정 및 문서 개선
